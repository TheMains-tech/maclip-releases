# Maclip releases

Downloads and the Sparkle update feed for [Maclip](https://github.com/TheMains-tech/Maclip), a native macOS clipboard manager.

## Download

**[Maclip 0.2.1 (DMG)](https://themains-tech.github.io/maclip-releases/Maclip-0.2.1.dmg)** — requires macOS 15 or later. Signed and notarized.

Open the DMG, drag Maclip to Applications, and launch it. Installed copies update themselves.
